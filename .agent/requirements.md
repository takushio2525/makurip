## 決定事項と理由（2026-10-31 にユーザーと決定）

### 名前: Makurip（マクリップ）

- 「MaClip」を日本語で読んだ音「マクリップ」に、「履歴を**まくる**」をかけている
- MaClipboard・MaClip・Macopy は同じ名前が既にあったので外した

### 技術: Swift（SwiftUI + AppKit）、メニューバー常駐・Dock に出さない

- Electron・Tauri とも比べたうえで決めた
- 理由: 常駐アプリとしての軽さ。NSPasteboard・グローバルショートカット・アクセシビリティ API を直接扱えること

### 履歴を呼び出す既定キー: ⌃⌘V

- ユーザーが選んだ
- Clipy の「履歴を開く」の既定キーと同じなので、フェーズ4で変えられるようにする

### 競合との差別化（Makurip の売り）

Clipy はメニュー形式、Maccy は検索中心の一覧。Makurip はこれらにない次の点を売りにする。

1. **絞り込み**: どうコピーしたか（キー操作か、コピーボタンなどか）・何をコピーしたか（種類）・コピー元のアプリで絞り込める
2. **大きなプレビュー**: 画像やコードを大きくプレビューできる
3. **全操作のキー割り当て**: すべての操作のキーを割り当て直せる
4. **開発・AI チャット向け**: コードの色付け、コマンドの先頭の「$ 」を外して貼る、取れる場合はコピー元のページを出す
5. **日本語に強い検索**: ひらがなとカタカナ、全角と半角を区別しない。「kopi」のようなローマ字で「コピー」を引ける
6. **AI 用の口（CLI / MCP）**: 履歴への追加はできる。中身は見せず、形式の情報だけを渡す。秘密の判定はアプリの中で形式から行う
7. **定型文（スニペット）**

### UI とアイコンのデザイン（2026-10-31 ユーザーが決定）

- UI は**案 B**: カーソル横に出す小さめのパネル（Windows の Win+V 型）。上のタブで種類を切り替えるカード一覧、⌘Y で大きいプレビュー。試作は `~/dev/makurip-design/ui/b.html`（別の worker の作業場。読むだけで触らない）
- アイコンは**案 B「パラパラ」**: 付箋の束を扇形にめくる。#11 で組み込み済み。原稿と再生成の手順は `design/icon/`（README.md）、ビルド入力は `Resources/`

### 候補窓（予測変換のような貼り付け）（2026-10-31 追加）

- ~~⌃⌘V は最終的に、押すとすぐ最新の履歴を貼り、文字カーソルのすぐ下に予測変換のような候補窓を出す動きにする~~（同日の追加決定で、出す位置を「カーソルの横」に変更）
- ⌃⌘V は最終的に、押すとすぐ最新の履歴を貼り、予測変換のような候補窓を出す動きにする
- 候補窓では、↑↓ で貼った中身が前・後の履歴に差し替わり、Tab で確定、Esc で取り消して貼る前に戻す。1 キーで大きい一覧へ広げられる
- キーは設定で変えられる（フェーズ4）
- フェーズ1 では ⌃⌘V は仮の一覧を開くままにする（受け入れ条件は変えない）。候補窓はフェーズ2 の後（フェーズ2.5）で作る

#### 追加の決定（2026-10-31・ユーザー）

- 位置: 文字カーソルの横（右）に出し、選んでいる行をカーソルの行の高さにそろえる。上が過去、下が新しい履歴（↑ で過去へ）
- 貼り方: 既定は、すぐ仮に貼って差し替える。ターミナルとチャット系のアプリだけは、Tab で確定したときに初めて貼るのを既定にし、アプリごとに設定で変えられる
- 試作（`~/dev/makurip-design/ui/candidate.html`）は窓を下に出しているが、位置はこの決定（横）を正とする。並び順の設定（ターミナル式・予測変換式）と、Enter でも確定できる点は試作どおり残す

### 一覧のカードのクリックと右クリック（2026-11-04 ユーザーの依頼・#38）

- カードを左クリックしたら、その項目を元のアプリへ貼る（選んで ↩ を押したのと同じ）。押したままカードの外へ出て離したときは貼らない。
  ~~試作どおりクリックで選ぶだけ・ダブルクリックで貼る~~（この依頼で変えた）
- カードを右クリック（⌃ を押しながらのクリックも）したら、そのカードを選んで操作のメニューを出す。並びは
  貼り付け・文字だけで貼り付け・クリップボードにコピー｜ピン留め（外す）・定型文に登録…・プレビュー・コピー元のページを開く｜履歴から削除。
  各項目の右にはキーマップのキーを出す（付け替えたらメニューの表示も変わる）
- 項目は状況で出し分ける: 文字だけで貼り付け・定型文に登録は文字を持つ項目だけ（画像・ファイルには出さない）、定型文に登録は秘密っぽい項目には出さない（#25）、
  コピー元のページを開くは開けるページがあるときだけ、ピン留めは状態で文言を変える
- 定型文の一覧（⌘S）のカードも同じ（クリックで貼る。右クリックは貼り付け・クリップボードにコピー・編集…・プレビュー）
- 秘密の項目は、いまの保護をそのまま通す（カードは伏せ字・貼るときとコピーするときは ConcealedType の印）。クリップボードにコピーしても新しい履歴にしない
- 範囲外: 候補窓・⌘Y のプレビューの中・メニューバーのメニュー

#### 実装する人が決めたこと（worker 判断・2026-11-04）

- 「この文を貼り付け」は、メニューの先頭の「貼り付け」（クリックと同じ）と「文字だけで貼り付け」の 2 つと読んだ（master の読み）
- 「文字だけで貼り付け」は新しい操作にせず、いまある `pastePlain`（⇧↩。書式を外す・プロンプトは外さない）に寄せた。キーと設定の項目（`keys.pastePlain`）もそのまま
- 「クリップボードにコピー」もいまある `copyOnly` に寄せ、既定のキーは ⌘↩（試作どおり）のままにした。⌘C は一覧の検索欄の編集に取ってあり
  （`KeyRules.searchField`。設定でも割り当てられない）、パネルの中で空いていないため。新しい操作は足していない
  （メニューの項目はどれもキーマップの操作そのもので、設定画面・CLI の `keys.<ID>` で付け替えられる）
- 1 回のクリックで貼るので、ダブルクリックすると 2 回目のクリックは閉じたパネルの後ろ（元のアプリ）に届く（文字カーソルが動きうる）。慣れの問題として残した（README に書いた）

### 設定は最初から AI が操作できる作りにする（2026-10-31 追加）

- 設定画面と CLI / MCP が、同じ「設定項目の一覧（スキーマ）」を共有する。項目ごとに ID・型・既定値・取りうる値・人が読める説明を持たせ、AI が自然言語の頼みを該当の項目に結びつけられるようにする
- 設定には秘密を入れないので、AI が読むのも書くのもよい。履歴の中身は、これまでどおり AI に見せない
- キーは「全部結構自由に」変えられる。対象は、呼び出し・候補窓の ↑↓/Tab/Esc/広げる・一覧の中の操作・絞り込みの切り替えのすべて。重なったキーを検出する
- 「貼り付けのときに UI を出すか」を設定の項目にする。⌃⌘V の動きを「すぐ貼るだけ／すぐ貼って候補窓／一覧を開く」から選べる
- 設定を CLI / MCP で変える口は、フェーズ6 を待たずフェーズ4 で作る（CLI）。MCP はフェーズ6 で同じスキーマを使う

## フェーズ1 で決めた実装上の方針（worker 判断・2026-10-31）

理由と比べた代替の全文は `.agent/architecture.md` の「技術選定」節。

- プロジェクトの作り方: SwiftPM（`Package.swift`）+ `scripts/build-app.sh` で .app を組み立てて署名
- 永続化: macOS 同梱の SQLite を C API で直接使う（外部ライブラリなし）
- グローバルショートカット: Carbon の `RegisterEventHotKey` を直接使う（外部ライブラリなし）
- 署名: キーチェーンの Apple Development 証明書。指定は git 管理外の `Config/signing.local.env`
- 置き場所: `~/Applications/Makurip.app`（アクセシビリティの許可が 1 回で済むよう、場所と署名を固定）

## フェーズ2.5 で決めた実装上の方針（worker 判断・2026-10-31）

理由と比べた代替の全文は `.agent/architecture.md` の「技術選定（フェーズ2.5）」と `.agent/conventions.md` の「候補窓」。

- ⌃⌘V の動きは 3 つとも作り、UserDefaults の `hotkeyMode`（`paste` / `candidate` / `list`。既定 `candidate`）で切り替える。選ぶ画面は #4
- 一覧を直接開くキー ⌃⌥⌘V を足した（メニューの「履歴の一覧を開く」も同じキーを出す）
- 横取りは候補窓の間だけの CGEventTap。システムに止められたら付け直さずに閉じる。何も押さないまま 10 秒で確定して閉じる
- 差し替えは「範囲を選び直す → ⌘Z → 確定まで貼らない」の順で、どれも AX で結果を確かめられるときだけ使う。
  入力欄を AX で読めないアプリでは、ユーザーが決めたターミナル・チャットと同じく確定まで貼らない（安全側）
- 変換中は仮に貼らず、変換が終わるまでキーも横取りしない。変換中か判定できないときは仮に貼らない（キーは横取りする）
- 見えている 8 行の送り方は試作どおり（選んだ行が 8 行目より下なら、いつも見えている範囲のいちばん下）。ターミナル式では ↑ でたどる間、
  窓は動かず一覧が流れ、選んだ行がカーソルの行にとどまる
- 仮に貼らない理由（確定まで貼らないアプリ・変換中など）を、窓の下に 1 行の注記で出す（試作の秘密の注記と同じ形）

## フェーズ4 で決めた実装上の方針（worker 判断・2026-10-31）

理由と比べた代替の全文は `.agent/architecture.md` の「技術選定（フェーズ4）」、限界は `.agent/conventions.md` の「設定」。

- 設定はデータフォルダの `settings.json`（既定と違う値だけ）。スキーマと検証は Core の `SettingsSchema` の 1 か所で、設定画面・CLI・ファイルの読み込みが同じ関数を通す
- 動いているアプリはファイルの監視で読み直し、上限・ホットキー・キーマップ・候補窓の動きをその場で当て直す（再起動は要らない）
- CLI は `Makurip --settings list|get|set|add|remove|reset|schema [--json]`。検証に通らない値は理由付きで拒否する（終了コード 2）。AI 向けの手順は `docs/ai-settings.md`
- キーの重なりは、設定画面では試作どおり前の割り当てから外し、CLI では拒否する（`--take-over` で付け替え）。ファイルの中の重なりはそのまま読んで画面と `list` に出す
- 使えないキー: どこからでも効くキーは ⌃・⌥・⌘ のどれかが要り、⌘ だけ（⌘C など）と macOS の操作は不可・1 つだけ。一覧と候補窓では文字のキーに ⌘・⌃・⌥ が要る
- 設定画面は試作どおりの 1 つの一覧。試作に無い項目（件数・容量の上限・記録しないアプリ・確定まで貼らないアプリ・ログイン時に起動・候補窓を自動で閉じるまで）を同じ形で足した。
  差し替え方式の決め打ち（`candReplaceMethod`）は手直し用なので画面に出さず、CLI と AI だけで変える
- UserDefaults の候補窓の設定（#8）は、既定のデータフォルダで最初に起動したときに引き継いで消す。起動引数で上書きする口（`-hotkeyMode` など）はなくした
- プライバシーを守る振る舞い（ConcealedType 等を保存しない）と内部の定数（監視の間隔など）は設定にしない（Issue #4 の所見 6・7）

## フェーズ5 で決めた実装上の方針（worker 判断・2026-10-31）

理由と比べた代替の全文は `.agent/architecture.md` の「技術選定（フェーズ5）」、判定の一覧と限界は `.agent/conventions.md` の「秘密の判定」。

- 判定は形式だけ（既知の接頭辞・秘密鍵・認証ヘッダー・URL の中のパスワード・.env などの代入・ランダムな文字列）で、アプリの中だけで行う。外部ライブラリは使わない
- 確度を 2 段に分ける。「高」（既知の形式・文脈のあるもの）は `secretLikely` と `secretKnownFormat`、「中」（形式から外れるランダムな文字列）は `secretLikely` だけ。
  マスクはどちらも、自動消去は「高」だけ（誤判定で普通のテキストを消さないため）
- 一覧用の平文（`preview_text`）は取り込みのときに伏せ字で保存する（どの画面・検索・後の AI の口からも中身が出ないように）。
  見せるのは決まった形の接頭辞と、十分に長い値の末尾 4 文字だけ（試作の `sk-test-••••••••••••••••0000`）
- ⌥（`keys.reveal`。修飾キー 1 つで付け替えられる）を押している間と、⌘Y の「押している間だけ表示」を押している間だけ中身を出す（試作どおり）
- 候補窓では秘密を仮に貼らず、確定（⇥・↩・ダブルクリック）したときに初めて貼る（試作どおり）。ほかのキー・窓の外のクリック・無操作で閉じたときは貼らない
- 自動消去は、最後に使ってから既定 10 分（`secretAutoDeleteMinutes`・1〜1440 分）。根拠: パスワード管理アプリがクリップボードを消すまでの時間
  （1Password 90 秒・Bitwarden の選択肢は最大 5 分）より長く、キーを数か所に貼る作業が終わる長さ。消えるのは履歴だけで、元の場所とシステムのクリップボードには残る。
  「消さない」設定は作らない（プライバシーを守る振る舞いは設定にしない。#4 の所見 6）。残したいものはピン留めし、ピン留めした秘密は消さない（マスクは続ける）
- 消した秘密は DB のすき間と WAL に残さない（`secure_delete`・WAL の切り詰め）。秘密を貼るときは ConcealedType の印を足し、ほかのクリップボード履歴アプリに記録させない
- 既存の履歴には、判定の版が上がったとき（初めて入れたときを含む）に 1 回だけ当て直す（DB 版 2 の `meta` 表に版を覚える）。印は足すだけで外さない

## フェーズ7 で決めた実装上の方針（worker 判断・2026-10-31）

理由と比べた代替の全文は `.agent/architecture.md` の「技術選定（フェーズ7）」、限界は `.agent/conventions.md` の「定型文」。

- 定型文はデータフォルダの `snippets.json`（履歴の DB とは別。履歴の上限・消去では消えない）。検証は Core の `SnippetCollection.normalize` の 1 か所で、
  定型文の窓・ファイルの読み込み・（#6 の）AI の口が同じ関数を通す。動いているアプリはファイルの監視で読み直す
- 呼び出しは試作どおり、一覧で ⌘S（定型文の一覧。種類と絞り込みは薄く・差し込みは色の札）→ ↩・⌘1〜9 で貼る。候補窓には混ぜない
- 差し込みは試作の 4 つ（`{{日付}}`・`{{クリップボード}}`・`{{言語}}`・`{{カーソル}}`）。`{{クリップボード}}` は試作どおり履歴のいちばん新しい文字（秘密っぽいものは飛ばす）。
  `{{カーソル}}` は貼った後に文字カーソルをそこへ動かす（AX で確かめられるときだけ。試作の見本は消すだけ）
- 日付の書き方を設定に足した（`snippetDateFormat`: 2026/10/31（既定・試作）・2026-10-31・2026年10月31日）
- 登録・編集・削除・並べ替えは専用の「定型文」の窓（試作に無い。見た目は設定シートにそろえた）。入口は一覧の ⇧⌘S（`editSnippet`。
  定型文の一覧では選んだものを編集、履歴の一覧では選んだ項目から登録）とメニューの「定型文を編集…」。
  一覧のパネルで編集しない理由: パネルは前面を奪わず ↩ が貼り付けで、複数行の本文と日本語入力を落ち着いて打てないため
- 試作の「略語」（`;date` など）は、検索で引ける語として持つ（打って展開する機能は作っていない）

## フェーズ6 で決めた実装上の方針（worker 判断・2026-10-31）

理由と比べた代替の全文は `.agent/architecture.md` の「技術選定（フェーズ6）」、限界は `.agent/conventions.md` の「AI の口」、使い方は `docs/ai-mcp.md`。

- AI の口は MCP（同じ実行ファイルの `--mcp`。stdio の JSON-RPC を自前で書いた。外部ライブラリは 0 のまま）と、同じ道具の CLI（`--ai`）。
  道具は履歴への追加（文字・画像・ファイルの参照。クリップボードにも置くかを選べる）・形式の情報の一覧・秘密の削除（確度で絞る）・条件での削除・
  定型文の登録・一覧・削除（#7 がマージ済みだったので足した）・設定の読み書き（#4 の CLI をそのまま通す）
- **既定はオフ。オンにできるのは設定画面だけ**（ユーザーに示して了承を得た「履歴は秘密も入りうるので、使うときだけオンにする」）。
  オン・オフは設定のスキーマ・設定ファイルに載せず、履歴の DB の `meta` に置く（AI が設定の口から自分で開けないように。#4 の所見 6 の考え方）。
  オフのとき、履歴と定型文の道具は「ユーザーが設定画面でオンにする必要がある」と答える。CLI の `disable` でオフにはできる
- 設定を読む道具（`settings_schema`・`settings_list`・`settings_get`）はオフでも使える（設定に秘密は入っていない）。
  設定を変える道具（`settings_set`・`settings_reset`）はオンのときだけ（#26。上限を下げると履歴が消え、記録しないアプリを外すと記録が増えるので、
  履歴を消す道具と同じ門に置く。MCP の注釈は `destructiveHint: true`）。人が使う設定の CLI（`--settings`）には門を付けない
  （ユーザーの道具で、シェルを使えるものは `sqlite3` でも門を開けられる。`docs/ai-settings.md` で、消す・記録を増やす変更はユーザーに確かめてから行うよう AI に頼む）
- 一覧で返すのは形式の情報だけ。中身・一覧用の平文・コピー元ページの URL（ホスト名だけは返す。`--dump-metadata` と同じ）・ファイルの名前とパスに加えて、
  内容のハッシュ（短い秘密は推した値のハッシュで当てられる）と秘密の項目の大きさ（伏せ字が長さを隠すのと同じ）も返さない。秘密の形式の名前は返す（「さっきの API キー」を選べるように）
- AI が足したものには `addedByAI` の印を付け、一覧のコピー元アプリは「AI（MCP の相手の名前）」にする（その名前で絞り込める）。種類・秘密の判定はふつうのコピーと同じ。
  人がコピーした項目に同じ内容があっても合流させない（合流すると、推した文字列が履歴にあるかが結果から分かり、人の項目のコピー元・印も書き換わる。#24）
- 門の外の出口（`--dump-metadata`）にも、中身を推せる値（内容のハッシュ・秘密の項目の大きさ）を出さない（#23）
- AI が行ったこと（メタデータだけ）は `ai-activity.jsonl` に残し、設定画面の「AI の口」の行と `--ai log` で見せる。登録コマンド（`claude mcp add …`）も同じ行に出してコピーできる。
  実際の登録はユーザーが行う（Makurip から `claude` は実行しない）
- 動いているアプリとは同じ DB（WAL）を使い、書いたら分散通知で知らせて一覧と秘密の自動消去を当て直す。アプリが動いていなくても使える

## プライバシーと安全（全フェーズ共通・最重要）

- 実際のコピー内容・実履歴の中身を、ログ・コミット・Issue・AI への出力に出さない
- 検証はメタデータか、自分で作ったテストデータで行う
- 開発・テストでは隔離したデータフォルダ（`--data-dir`）を使い、検証後に消す
- 単体テストは一般ペーストボードではなく、一意な名前の `NSPasteboard(name:)` を使う
- 自動テストでは前面のアプリにキーを送らない。貼り付けの E2E は専用の TextEdit 書類の pid を宛先にする
- パスワード管理アプリが付ける `org.nspasteboard.ConcealedType` 等の付いた項目は保存しない
