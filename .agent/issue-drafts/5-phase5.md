[フェーズ5] 秘密っぽいものの検出・マスク表示・自動消去

## 目的
「AIからのは，APIキーのコピーとかもあると思うから，十分注意しなきゃならない」「中はみずに形式だけでキー判断みたいな」（ユーザー原文）。

詳細は `.agent/requirements.md` を正とする。

## 範囲
- API キー・トークン等を形式から判定する（判定はアプリの中だけで行い、中身を外へ出さない）
- 判定結果は `ClipFlag.secretLikely`（`ClipStore.setFlags(_:id:)`）
- 一覧ではマスク表示、一定時間後に自動消去
- パスワード管理アプリの ConcealedType 等はフェーズ1 で既に保存しない
