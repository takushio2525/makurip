[フェーズ1] 土台: 全型の取り込み・永続化・⌃⌘V の仮一覧・元のアプリへの貼り付け

## 目的
コピーされたものを種類を問わず取りこぼさず保存し、再起動後も残す。⌃⌘V で開く仮の一覧から選ぶと、元いたアプリにそのまま貼り付けられる。一覧の UI は仮（本番はフェーズ2）。

詳細は `.agent/requirements.md` を正とする。

## 範囲
- 一般ペーストボードの監視。各 NSPasteboardItem の全型とデータの組を保存（テキスト・RTF・HTML・画像・PDF・ファイル URL・色・アプリ独自の型）。大きいデータはディスクへ、サイズ上限、重複は先頭へ
- `org.nspasteboard.ConcealedType` / `TransientType` / `AutoGeneratedType` は保存しない
- メタデータ: 時刻・コピー元アプリ・コピー方法（キー操作 / それ以外）・種類・コピー元ページ URL・ピン留め・フラグ欄
- 種類とコピー方法の判定は純粋関数 + 単体テスト。限界を `.agent/conventions.md` に書く
- `~/Library/Application Support/` 配下に永続化、件数の上限
- 書き戻しは全型、元のアプリへフォーカスを返して ⌘V。書き戻しを新しい履歴にしない
- ⌃⌘V の仮一覧（絞り込み・↑↓・Enter・Esc）。UI 層は `MakuripUI` に切り離す
- メニューバーのアイコン（仮）とメニュー、メタデータだけの書き出し

## 受け入れ条件
1. 書いてある手順でクリーンにビルドが通り、単体テストがすべて通る（種類・コピー方法・ConcealedType・重複）
2. ~/Applications/Makurip.app がメニューバーだけに出て起動し、固定の証明書で署名されている
3. 隔離したデータフォルダで、テキスト・RTF・画像・ファイル URL が正しい種類で記録され、ConcealedType の項目がない
4. 再起動しても書き出し結果が同じ
5. キー操作のコピーとそれ以外が分かれる（限界を明記）
6. ⌃⌘V で仮の一覧が開き、絞り込め、Enter で全型がペーストボードに戻り、隔離した TextEdit へ貼れる
7. 貼っても履歴に重複ができない
