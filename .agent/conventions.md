# 規約（命名・ログ・エラー・テスト・判定の限界）

## 命名

| 対象 | 規則 | 例 |
|---|---|---|
| ファイル | 中心の型の名前（PascalCase） | `ClipStore.swift` |
| 型 | PascalCase | `PasteboardSnapshot` |
| 関数・変数 | camelCase | `acknowledgeOwnWrite` |
| DB の表・列 | snake_case | `last_used_at` |
| 起動引数 | `--kebab-case` | `--data-dir` |
| 分散通知（検証用） | `com.takushio2525.makurip.debug.<命令>` | `...debug.toggleHistory` |
| 設定項目の ID | camelCase（候補窓の 5 つは UserDefaults の時代の名前のまま）。キーは `keys.<KeyAction の ID>` | `maxItems`・`candPasteTiming`・`keys.open` |

UI に出す文言は日本語。絵文字は使わない。

## ログ（最重要: 中身を書かない）

- `os.Logger`（サブシステム = バンドル ID、カテゴリ `app` / `capture` / `paste`）
- 書いてよいのは **メタデータだけ**: 種類・コピー方法・型の数・バイト数・スキップの理由・結果
- **平文・データ・プレビュー・コピー元ページの URL は書かない**。`privacy: .public` を付けるのはメタデータの値だけ
- 見るとき: `log stream --predicate 'subsystem == "com.takushio2525.makurip"' --info`

## エラー

- ストア・SQLite は `throws`（`SQLiteDatabase.Failure`）。呼ぶ側（アプリ）はログに残して続ける。起動時に開けなければ終了する
- 取り込みの失敗は `PasteboardMonitor.Event.failed` で返す（落とさない）

## テスト

- 単体テストは Swift Testing（`@Test` / `#expect`）。`swift test` で全部回る
- **一般ペーストボードを使わない**。`NSPasteboard(name:)` に一意な名前を付け、終わったら `releaseGlobally()`
- ストアのテストは一時フォルダ（`TemporaryDirectory`）。既定のデータフォルダに触らない
- テストデータは自作（`Tests/MakuripCoreTests/Fixtures.swift`・`MakuripDevTool pb-write`）
- E2E（`scripts/e2e/`）は `--data-dir` で隔離し、終わったら消す。起動したインスタンスは必ず終了させる
- UI のテスト（`MakuripUITests`）は `@MainActor` で動く。重い処理（大きい画像を作る等）をテストごとにメインで行わない。
  ペーストボード監視のテストはメインの 0.05 秒後のタイマーを 400 ms 以内に待つので、メインを塞ぐと落ちる
- 見た目の検証（`SnapshotTests`）と速さの計測は環境変数 `MAKURIP_SNAPSHOT_DIR` を付けたときだけ動く（`make ui-compare`）

## 判定の限界（正直に書く）

### 種類（`KindClassifier` / `TextHeuristics`）

経験則なので、次は見分けられない・間違えうる。

- **短い断片**: 「`x = 1`」のような 1 行は、手がかりが 2 つ以上ないとコードにならない。逆に「`a == b`」を含む文章はコードになりうる
- **コードを含む Markdown**: 途中に ``` がある文書はテキスト扱い（AI チャットの回答をまるごとコピーした場合など）。全体が ``` で囲まれていればコード
- **コマンド**: 先頭の語が既知の CLI の一覧（`TextHeuristics.knownCommands`）にあるか、1 行目がプロンプト（`$ ` `% ` `❯ ` `➜ `・`user@host:~$ ` などの PS1）で始まるときだけ。一覧にない自作のツールは「テキスト」になる。
  root の `# ` は、**全部の行が「# 既知のコマンド …」のときだけ**コマンドにする（「# 見出し」「# コメント」と区別するため）。「# make targets」のように見出しの頭が小文字の既知のコマンドだと、コマンドになってしまう（Markdown の見出しはふつう大文字か日本語で始まるので許した）
- **SQL・YAML・HTML（フェーズ3）**: SQL は頭のキーワードが大文字か、行末が「;」のときだけ（「Select the best option」のような英文を外す）。YAML は `key:` の行が 2 つ以上あり、入れ子の `key:`・`- ` の並び・`---` のどれかがあるもの（「Note: …」の並びは外れる）。HTML・XML はタグで始まりタグで閉じ、閉じタグがあるもの
- **リッチテキスト**: RTF・HTML の型が載っているかで決める。VS Code やターミナルは色付きの RTF/HTML も載せるが、中身がコード・コマンドならそちらを優先する。整形のない文章でも RTF を載せるアプリ（Pages 等）はリッチテキストになる
- **画像と文章が両方あるとき**: Office は文章にプレビュー画像（PNG/PDF）を添えるので、文章があればリッチテキスト。平文が URL かパスだけなら画像（ブラウザの「画像をコピー」）
- **PDF だけ**: 画像として扱う（種類に PDF がないため）
- **色**: 色の型（`com.apple.cocoa.pasteboard.color`）か、`#RRGGBB` / `rgb()` / `hsl()` の 1 語だけ。色名（`red`）は色にしない
- **ファイル**: `file://` の URL があれば何があってもファイル（Finder はアイコン画像と名前の平文も載せるため）

### コピー方法（`CopyMethodClassifier`）

- **キー操作の判定にはアクセシビリティの許可が要る**。許可がないあいだは全部「不明」（「それ以外」と混ぜない）
- ⌘C を押したが何もコピーされず、1 秒以内にボタンでコピーすると「キー操作」になる
- ⌘C から 1 秒より遅れてペーストボードに書くアプリは「それ以外」になる
- ⌘C を他のキーに割り当てているアプリ、メニューの「コピー」をマウスで選んだ場合は「それ以外」（正しい）
- 自動操作（他のプロセスが `postToPid` で送った ⌘C）はグローバル監視に見えないので「それ以外」
- セキュア入力中（パスワード欄など）はキーが見えない（その場合、コピー自体もふつう ConcealedType が付く）
- ⌃ を伴う ⌃⌘C などは別の操作とみなす

### 取り込み（`PasteboardMonitor`）

- ペーストボードには変化の通知がないので 0.25 秒おきに見る。**それより速く上書きされたコピーは最後の 1 回だけ**になる（上書きされた中身は読みようがない）。書き込みが落ち着くまで 0.08 秒待つので、0.3 秒より短い間隔の連続コピーはまとまる
- コピー元のアプリは「変化を見つけた時点で前面にいたアプリ」（⌘C のときは押した瞬間）。コピーしてすぐ別のアプリへ切り替えると、切り替え先になることがある。バックグラウンドのアプリが書いた場合も前面のアプリになる
- 遅延で渡すデータ（promise）は読んだ時点で書き手に作らせる。書き手が終了していると読めない型は落ちる
- 同じ内容の判定は「全項目・全型のデータが同じ」（コピーのたびに変わる付随情報の型は除く。`PasteboardMarkers.volatileTypePrefixes`）。同じ文字列でもコピー元のアプリが違って型の組が違えば別の履歴になる
- コピー元ページの URL は Chromium 系（`org.chromium.source-url`）と WebKit の webarchive だけ。Firefox・コピーボタン（`navigator.clipboard.writeText`）は取れない

### 貼り付け（`Paster`）

- ⌘V は仮想キーコード 9 + 文字 "v" で送る。⌘V を別のキーに割り当てているアプリでは貼れない
- 元のアプリが終了していたら ⌘V は送らない（ペーストボードには載っている）

### 検索（`SearchText` / `HistoryFilter`）

- 探す対象は一覧の平文（先頭 1000 文字）・アプリ名・種類名・コピー元ページのホスト名。**1000 文字より後ろの文章は検索に入らない**（プレビューでは全文を出す）。画像の中の文字も探さない
- 漢字は読みで引けない（「てじゅん」で「手順」は出ない）。ローマ字が効くのは、英字だけで 2 文字以上の語をかなとして読める場合だけ。英語の語は綴りのまま一致する（読みの候補を足すだけ）
- ローマ字の読みは 1 通り（「si」も「shi」も「し」）。「n」の直後に母音・y が来ると「な行」になる（「kani」は「かに」。「かんい」は「kan'i」と打つ。子音の前の「nn」は「ん」1 つ）
- 開いて 0.2 秒以内に打つと、検索用の正規化がまだ済んでおらず、1 回目の打鍵だけ遅い（5000 件で 0.24 秒）

### パネルの位置（`InsertionPointLocator` / `PanelPlacement`）

- 文字カーソルは AX で取る。アクセシビリティの許可がないとき、ターミナル・Electron 製（VS Code・Slack 等）・一部の Web の入力欄は取れないことが多く、入力欄の枠 → マウスの位置の順で代わりにする
- 入力欄の枠しか取れないアプリでは、枠の左下を基準にする（大きいテキストビューだと、書いている行から離れた所に出る）
- 問い合わせの待ちは 0.15 秒で切る（応答しないアプリで止まらないように）

### 候補窓（`CandidateCoordinator` / `KeyEventTap` / `ReplacePlanner`）

**横取りを残さないための決まり**（いちばん大事。変えるときは `CandidateInterceptLifetimeTests` に経路を足す）

- タップを作るのは `CandidateCoordinator.start` だけ。閉じる経路（⇥・↩・esc・広げる・ほかのキー・窓の外のクリック・ダブルクリック・
  10 秒の無操作・前面のアプリの切り替え・窓が閉じられた・スペースの切り替え・画面のスリープ・ログアウト画面・画面の構成の変化・
  タップが止められた・差し替えの失敗・Makurip の終了）はすべて `end` を通り、その場でタップを止める。文書の後始末はその後で、タップなしで行う
- システムがタップを止めたら（`tapDisabledByTimeout`・`tapDisabledByUserInput`）**付け直さない**。候補窓を閉じる。
  応答が遅れた状態で横取りを続けると、キーが届かないまま食べられうるため
- Makurip が落ちたときは、タップの mach port がプロセスと一緒に消えるので、横取りも消える（OS の仕組み。テストでは確かめられない）。
  固まったときは、システムがタップを止める（上と同じ）
- タップの中の処理は短く（AX の問い合わせは 0.1 秒で切る）。文書への反映は別の流れ（`drain`）で行う
- Makurip が送ったキー（⌘V・⌘Z・⌘⇧Z・⌫）には印（`SyntheticEventMarker`）を付け、タップはそれを見ずに素通しする

**変換中**

- 判定は、AX の未確定の範囲（`AXTextInputMarkedRange`。WebKit は `AXTextInputMarkedTextMarkerRange`）。読めなければ入力ソースで近似する
  （日本語入力のかなモードなど英字以外 → **判定できない**。英字・ふつうの配列 → 変換中ではない）
- 変換中に ⌃⌘V を押したら: 仮に貼らない（確定まで貼らない方式）。変換が終わるまでは ↑↓・⇥・↩・esc も横取りしない（日本語入力のもの）
- 判定できないときは**安全側**: 仮に貼らない（未確定の文字があるところへ ⌘V を送ると、確定のされ方がアプリで違うため）。
  キーは横取りする（取り消しは esc でいつでもでき、確定するまで文書に何も送らないので、間違って横取りしても文書は変わらない）
- 候補窓の間に文字のキーを押すと、そこで確定して閉じ、そのキーは前面のアプリへ渡る。なので候補窓と日本語入力の変換が同時に起きることはない

**差し替え**

- 方式は「範囲を選び直す → ⌘Z → 確定まで貼らない」の順。どれも**結果を AX で確かめられるときだけ**使う。入力欄の選択範囲を
  AX で読めないアプリ（ターミナル・多くの Electron 製・入力欄でない所）では仮に貼らない（⌘Z を確かめずに送ると、Finder などで別の操作を取り消すため）
- 範囲の選び直しは、文字だけの中身で、貼る前後の文字カーソルから測った長さが中身の文字数（UTF-16）と同じときだけ。
  改行の変換・自動の字下げ・スマート引用符などで長さが変わるアプリ、画像・リッチテキストは ⌘Z
- 始めに文字を選んでいたら ⌘Z（貼り付けが選択を置き換えるので、範囲を消しても元の文字は戻らない）
- ⌘Z で戻ったかは「選択の位置と文字数が貼る前と同じか」で見る。戻らなければ ⌘⇧Z で打ち消して、貼ってあるもので閉じる。
  失敗した方式はアプリごとにメモリで覚え、次からはその次の方式で始める（再起動で忘れる。決め打ちは `candReplaceMethod`）
- 範囲を選び直して差し替えたあとの取り消しは「範囲を選んで ⌫」なので、相手のアプリの取り消しの履歴には途中の差し替えが残る
- 取り消し・広げるの後始末（⌘Z など）は数十〜数百 ms かかる。その間に打った文字は、後始末より先に入りうる
- ほかのキーで確定したとき、まだ差し替えが終わっていなければ、そのキーが先に入り、差し替えが後から入る

**確定まで貼らないアプリ**（`DeferredPasteApps`。アプリごとに `candPasteTiming` で変えられる）

- ターミナル: ターミナル（`com.apple.Terminal`）・iTerm2・Warp・Ghostty・tako・Alacritty・kitty・WezTerm・Hyper・Tabby
- チャット: Slack・Discord・LINE・メッセージ・Microsoft Teams・ChatGPT・Claude・Telegram・WhatsApp
- バンドル ID は手元の .app で確かめた（手元に無いものはコードに「未確認」と書いた）。一覧に無いターミナル・チャットは
  「入力欄を読めない」ので、たいてい確定まで貼らない側に落ちる

**そのほか**

- ペーストボードの控えは、除外の印（パスワード等）が付いていても取り消しのために読む（メモリの中だけ。保存も記録もしない）。256 MB を超えたら控えない
- 何も押さないまま 10 秒（`candIdleTimeout`）で確定して閉じる（仮に貼ったものは残る）
- 候補窓の数（行数・文字数）は一覧用の平文（先頭 1000 文字）から数える。切れていれば「+」を付ける

### コードの言語（`CodeLanguageDetector`）

- 見るのは一覧の平文（先頭 1000 文字）だけ。そこに手がかりがなく後ろにだけある長いコードは、言語が決まらない（色付けは最小限）
- 手がかりが少ない断片（1 行・数語）は決めない（`minimumScore` 4 点）。minify された JavaScript のように空白のない 1 行も決まらないことが多い
- 紛らわしい組は固有の手がかりで分ける: TypeScript は型の注釈（`: string`・`interface`）、C++ は `std::`・`#include <iostream>`、Kotlin は `fun`・`val`、Go は `package`・`:=`。どれもないと JavaScript・C・Swift 寄りになる
- Markdown のコードブロック（```lang）の言語名と shebang がいちばん強い。知らない言語名は「言語不明」
- 判定できる言語: Swift・JavaScript・TypeScript・Python・シェル・JSON・HTML・XML・CSS・Go・Rust・C・C++・Java・Kotlin・Ruby・SQL・YAML

### 色付け（`SyntaxHighlighter`）

- 字句だけを見る簡易なもの。正規表現のリテラル・文字列の中の式（`${…}`・`\(…)`）・JSX のタグは見分けない（文字列の色・ふつうの字になる）
- 「大文字で始まる名前は型」「`(` が続くか `.` の後ろの名前は関数」は試作と同じ決まり。定数（`MAX_SIZE`）も型の色になる
- 閉じない文字列は行末で、閉じないコメントは最後で止める（`"` や `/*` が 1 つあっても全体が文字列にならない。複数行を許すのは ``` ` ``` と 3 つ重ねの引用符だけ）
- シェルでは、プロンプトのある文字列の出力の行（プロンプトも続きでもない行）に色を付けない
- 言語不明のコードは文字列（`"` と ``` ` ```）・数・`//` と `/* */` のコメントだけに色を付ける

### プロンプトを外して貼る（`ShellPrompt` / `PastePipeline`）

壊さないことを優先し、迷う行は外さない。

- 外す: 行頭の `$ ` `% ` `❯ ` `➜ `、PS1（`user@host:~$ `・`[user@host dir]$ `・`user@host dir % `・`bash-3.2$ `・前に `(venv) `、oh-my-zsh の `➜  dir git:(main) ✗ `）、続き行の `> `（zsh の `dquote> ` なども。前の行が `\`・`|`・`&&` で終わるか、引用符・ヒアドキュメントが閉じていないときだけ）、全部の行が「# 既知のコマンド」のときの root の `# `
- 外さない: 出力の行（`$` や `%` で始まっていても、プロンプトの後ろに空白がなければ外さない。`$HOME`・`$(…)`・jQuery の `$(…)`）、行頭に空白のある行（字下げした `  $ ls` は外さない）、ほかにプロンプトの行があるときの `# `、`#!`、`➜  ~` のようにどこまでがプロンプトか分からない形
- 外した文字は文字の型（UTF-8・UTF-16）だけ。RTF・HTML（ターミナルが色付きで載せるもの）は元のまま書き戻すので、RTF・HTML を優先して読むアプリ（テキストエディットのリッチテキスト・メモなど）に貼ると「$ 」が残る。ターミナルとコードエディタは文字の型を読む
- 出力の行の頭が `$ ` のとき（`$ 5.00` のような金額）は、プロンプトと区別できず外れる
- ⇧↩（プレーンテキストで貼る）は外さない（元のまま貼る逃げ道。試作どおり）。候補窓から貼るときは外す（一覧から ↩ で貼るのと同じ）

### 一覧の表示

- カードのコピー方法は「キー」とだけ出す（⌘C と ⌘X を見分けて記録していない）
- ⌘⌫（履歴から削除）は、検索欄の「行頭まで消す」と同じキー。試作どおりにした。検索欄の編集を優先したいときは設定で替える（`keys.delete`）
- 検索欄で ⌘C・⌘X した文字も履歴に入る。パネルは元のアプリを前面のままにするので、コピー元は前面のアプリとして記録される
- コピー元のページは、題名を取り込んでいないので「ホスト　パス」で出す（試作は「題名　ドメイン」）。クエリ（`?` の後ろ）はトークンなどが入りうるので出さない。取れない項目（Firefox・ネイティブのアプリ・コピーボタン）では行ごと出さない
- ⌘Y のプレビューは先頭 2 万文字まで。見出しの行数・文字数は全文で数える（切ったときは「長いので先頭の … 文字だけを表示しています」を出す）

### 設定（`SettingsSchema` / `SettingsController` / `KeyRules`）

- **同時に書いたとき**: CLI と設定画面がほぼ同時に書くと、後から書いた方が残る（どちらも書く直前にファイルを読み直すので、間はごく短い。
  画面側は `SettingsController` の `set`・`reset`・`resetAll` が読み直してから当てる。見張りが外れていても、外の変更を手元の古い値で消さない）
- **ファイルの監視**: 変化から 0.05 秒待って読み直す。データフォルダそのものを動かしたり消したりすると見張りが外れる（起動し直すと戻る）
- **手で壊したとき**: 値が検証に通らない項目だけ既定に戻す（ほかの項目は使う）。JSON として読めなければ**すべて既定**で動く（呼び出しキーも ⌃⌘V に戻る）。
  次に画面か CLI で書くと `settings.broken.json` に退避してから書き直す
- **キーの決まり**: macOS の操作と重なるもの（`KeyRules.reservedGlobal`）は代表的なものだけ。ユーザーがシステム設定で付け替えたショートカットや、
  ほかのアプリのショートカットは見分けない。Carbon の登録が失敗したときだけ「登録できませんでした」と出す
  （ほかのアプリが同じキーを登録していても失敗しないことがある。そのときどちらに届くかは OS 次第。実機で確かめる #9）
- **キーは物理キーの位置**: 表記は US 配列の名前（JIS 配列でも英字・数字の位置は同じ。¥ と _ は JIS のキーとして別に持つ）
- **ログイン時の起動**: 値を変えたときだけ登録・解除する。システム設定のログイン項目から外しても、設定の値は true のまま（もう一度切り替えると合う）
- **記録しないアプリ**: 判定はコピー元と同じ「前面にいたアプリ」（バックグラウンドのアプリが書いたコピーは、前面のアプリとして判定される）
- **UserDefaults からの引き継ぎ**: 読むのは永続ドメインだけ。アプリごとの辞書は壊れた組だけを捨てる。既定のデータフォルダで、設定ファイルがないときの 1 回だけ
- **CLI と既定のデータフォルダ**: `--data-dir` を付けない CLI は本物の設定を書き換える（動いている Makurip にすぐ効く）。検証では必ず `--data-dir` を付ける


### 秘密の判定（`SecretDetector` / `SecretScanner` / `SecretMask` / `SecretExpiry`・#5）

判定は**形式だけ**（文字列の形と、名前・ヘッダーなどの文脈）で、アプリの中だけで行う。結果は印（`secretLikely`・`secretKnownFormat`）と、
種類と位置（`SecretFinding`）だけで、中身はどこにも送らない。ログ・状態の書き出しに出すのは件数と確度だけ。
`--dump-metadata` は項目ごとに印を出すが、秘密の項目の大きさ（全体・型ごと）は `size: "hidden"` で伏せ、内容のハッシュはどの項目にも出さない（#23。長さとハッシュで短い秘密を当てられるため）。

**見つけるもの**（確度「高」= `secretKnownFormat` も付ける。自動消去の対象）

| 種類 | 形（接頭辞は見せる。本体は伏せる） |
|---|---|
| Anthropic | `sk-ant-<語><数字>-` + 20 文字以上 |
| OpenAI | `sk-`（`proj-`・`svcacct-`・`test-` など小文字の語 1 つ）+ 20 文字以上（本体がランダムなときだけ） |
| GitHub | `ghp_`・`gho_`・`ghu_`・`ghs_`・`ghr_` + 36 文字、`github_pat_` + 22 文字以上 |
| GitLab | `glpat-` など + 20 文字以上 |
| Slack | `xoxb-` などのトークン・`xapp-`（本体がランダムなときだけ）、`https://hooks.slack.com/services/…` |
| Discord | `https://discord.com/api/webhooks/<数字>/<トークン>` |
| AWS | `AKIA`・`ASIA` などのアクセスキー ID（大文字・数字 16 文字） |
| Google | `AIza` + 35 文字、`GOCSPX-` + 28 文字、`ya29.` のアクセストークン |
| Stripe | `sk_live_`・`sk_test_`・`rk_…`・`whsec_`（`pk_` は公開してよい鍵なので拾わない） |
| npm・Hugging Face・SendGrid | `npm_` + 36 文字・`hf_` + 30 文字以上（大文字と小文字が入り混じるとき）・`SG.` + 22 + `.` + 43 |
| JWT | `eyJ…` `.` `eyJ…` `.` 署名（3 つの部分） |
| 秘密鍵 | `-----BEGIN … PRIVATE KEY-----`（RSA・EC・OPENSSH・PGP など。公開鍵・証明書は拾わない） |
| 認証ヘッダー | `Authorization: Bearer/Basic/Token …`（curl の `-H` の中も）、ラベルなしの `Bearer …`・`X-API-Key:`・`PRIVATE-TOKEN:`（値がランダムなときだけ） |
| URL の中のパスワード | `postgres://user:<ここ>@host` などの接続文字列 |
| 代入 | `.env`・シェル（`export NAME=…`）・INI・TOML・YAML・JSON・コードの文字列・URL のクエリ・CLI の `--password=` で、名前の最後の語が password・passwd・pwd・pass・secret・token・apikey・credentials か、`<api/access/secret/private/client など>_key`（`SECRET_KEY_BASE` のように最後の語が base・value なら前の語で見る） |

**確度「中」**（`secretLikely` だけ。マスクするが自動では消さない）: 文字列全体が 1 語で、20〜512 文字、大文字と小文字と数字が入り混じり、
ランダムらしいもの（文字の種類の切り替わりが 3 割以上・同じ大きさの英字が 5 文字以上続く部分が 35% 以下・エントロピーが十分）

**拾わないもの**（`SecretDetectorTests` の陰性の例）: UUID（区切りあり・なし）・16 進だけのもの（git のハッシュ・SHA-256）・ULID・
Base64 の画像（PNG・GIF・JPEG・PDF などの頭）や文章を符号化したもの・`data:` URL・URL・パス・メールアドレス・識別子（`base64EncodedStringWithOptions2`）・
版の文字列、名前が付随情報（`TOKEN_LIMIT`・`MAX_TOKENS`・`PASSWORD_MIN_LENGTH`・`API_KEY_PATH`）・ページ送り（`nextPageToken`）・公開の鍵（`PUBLIC_KEY`・`NEXT_PUBLIC_*`）、
値がプレースホルダ（`your-api-key`・`<token>`・`${TOKEN}`・`$(…)`・`xxxx`・`changeme`）・参照（`os.environ[…]`・`process.env.X`・`getToken()`・`settings.SECRET`）・
型の名前（`String`）・画面の文言（空白・日本語を含む値）

**見逃すもの**（限界）

- 形式のない短いパスワード・合言葉（名前の付いた代入でなければ拾えない。`hunter2` だけをコピーしても秘密と分からない）
- 空白を含むパスワード（代入の値に空白があると、文章と見分けられないので拾わない）・日本語の名前（`パスワード: …`）
- 小文字と数字だけ・大文字と数字だけのランダムな文字列（base36・base32 の TOTP の種など）、16 進だけのトークン（Twilio など）、英字だけの値（Hugging Face 以外）
- 文章の中に混ざった、形式のないランダムな語（確度「中」は文字列全体が 1 語のときだけ）
- 先頭 512 KB（UTF-16）より後ろにある秘密（数 MB のログで取り込みを遅くしないため。`SecretDetector.scanLimit`）
- 画像の中の文字（スクリーンショットに写ったキー。OCR はしない）・ファイルの中身（名前とパスだけを見る）
- 平文がある項目の RTF・HTML だけにある秘密（平文がないときだけ RTF・HTML の中身を見る）。2 つ目以降の項目の平文は見る

**誤判定するもの**（限界）

- 公開してよい値でも形式が同じもの: Supabase の anon key などの JWT・Firebase の Web API キー（`AIza…`）・AWS のアクセスキー ID だけ・
  ドキュメントの例示用の値（AWS の `AKIA…EXAMPLE` も形どおりなので拾う）
- 開発用の決まったパスワード（`POSTGRES_PASSWORD=postgres`）・パスワード再設定やログインのリンク（`?token=…`）も確度「高」で、時間が来ると消える
- ランダムに見える ID（Google ドライブのファイル ID だけをコピーしたもの・nanoid など）は確度「中」でマスクされる（消えはしない。⌥ で見える）

**伏せ字の作り方**（`SecretMask`）: 決まった形の接頭辞（`sk-ant-api03-`・`ghp_`・`AKIA`・秘密鍵の BEGIN と END の行）と、隠す部分が 16 文字以上残るときだけ
末尾 4 文字を見せる。パスワード・URL の中のパスワード・秘密鍵は末尾も見せない。伏せ字の数は 8 か 16 にそろえ、元の長さを出さない。
一覧用の平文（`preview_text`）は取り込みのときに**全文で伏せてから**先頭 1000 文字に切る（切れ目で秘密の一部がのぞかない）。
接頭辞の分からない値（試作の `tok-test-…`）は接頭辞を見せない（試作との差。`design/ui-compare/README.md`）

**表示**: 隠した内容は、表示のキー（既定 ⌥・`keys.reveal`）を押している間と、⌘Y の「押している間だけ表示」を押している間だけ出す。
一覧を閉じたとき・候補窓を閉じたときに隠した状態へ戻し、読んだ本当の中身（`ClipContentLoader.secret`）もメモリから捨てる。
一覧では、⌥ を押している間は見えている秘密の項目がすべて表示になる（試作どおり）。検索は中身では引けず、見えている接頭辞と「秘密」「ひみつ」で引ける

**候補窓**: 秘密は仮に貼らない（↑↓ で秘密に来たら、仮に貼ってあるものを戻す）。確定（⇥・↩・ダブルクリック）したときに初めて貼る。
ほかのキー・窓の外のクリック・無操作で閉じたときは、秘密は貼らずに貼る前へ戻す（はっきり確定したときだけ貼る）

**貼るとき**: 秘密は ConcealedType の印を足してペーストボードに書く（ほかのクリップボード履歴アプリに記録させない）。印の分、型が 1 つ増える

**自動消去**: 確度「高」だけ。最後に使ってから（取り込み直し・Makurip からの貼り付けで延びる）`secretAutoDeleteMinutes`（既定 10 分・1〜1440 分）で消す。
「消さない」設定はない（プライバシーを守る振る舞いは設定にしない方針）。残したいものはピン留めする（ピン留めは消さない。外すと、時間を過ぎていれば次の見回りで消える）。
時刻で掛けるタイマーなので、スリープ中に時間が来たものは起きたときに消える。Makurip が止まっていた間に時間が来たものは、次に起動したときに消える。
消したあとは SQLite の `secure_delete` と WAL の切り詰め（`wal_checkpoint(TRUNCATE)`）で、ファイルに中身を残さない（`blobs/` の大きいファイルは消すだけ。FileVault に任せる）。
システムのクリップボードそのものは消さない（履歴から消すだけ）

**既存の履歴への当て直し**: 判定の版（`SecretDetector.version`）が `meta` の `secretScanVersion` より新しいとき、起動時に裏のスレッドで 1 回だけ全件に当て直す
（文字の型だけを読み、画像は読まない）。印は足すだけで外さない。当て直しが終わるまでの短い間は、前の版で保存した秘密が伏せ字になっていない

### 定型文（`SnippetTemplate` / `SnippetClipboard` / `SnippetController`）

- **差し込みの記法**: `{{日付}}`・`{{クリップボード}}`・`{{言語}}`・`{{カーソル}}` の 4 つだけ（試作と同じ）。中の前後の空白（全角も）は無視する。
  知らない名前（`{{名前}}`）・閉じていない（`{{日付`）・中に改行・名前の部分が 24 文字を超えるものは、書いたままの文字として貼る。
  `{{日付}}` を文字のまま貼る書き方（エスケープ）はない
- **`{{クリップボード}}`**: いまのペーストボードではなく、履歴のいちばん新しい文字（テキスト・リッチテキスト・コード・コマンド・URL・色）。
  なので、記録しなかったコピー（パスワード管理アプリ・記録しないアプリ・一時停止中）は入らず、その前の履歴が入る。秘密っぽい項目（`secretLikely`。#5）は飛ばす。
  見るのは新しい 200 件まで（その中に文字がなければ空）。履歴が空なら空。コマンドのプロンプトは外さず、文字は手を加えずに入れる（末尾の改行も残る）
- **`{{言語}}`**: `{{クリップボード}}` の元がコードなら判定した言語（```swift などに使う名前。`CodeLanguage` の rawValue）、コマンドなら `shell`、それ以外・決まらなければ空
- **`{{日付}}`**: 貼った時刻の、Mac の時間帯での日付。暦は和暦の設定でも西暦。書き方は設定の `snippetDateFormat`
- **`{{カーソル}}`**: 文字としては消し、貼った後に文字カーソルをそこへ動かす。動かすのは、貼る前と後の入力欄を AX で読めて、カーソルが
  ちょうど貼った文字の後ろにあるときだけ（アクセシビリティの許可が要る。ターミナル・多くの Electron 製・改行を変換するアプリでは動かず、末尾のまま）。
  2 つ目からは消すだけ
- **貼り方**: 書き戻すのは文字の型（UTF-8）だけ。⇧↩（プレーンテキスト）も同じ文字。書き戻しは新しい履歴にしない。定型文を貼るとペーストボードは定型文の文字になる（履歴の貼り付けと同じ）
- **一覧での操作**: 定型文の一覧では、種類・コピー方法・アプリの絞り込み、ピン留め（⌘P）、削除（⌘⌫）は効かない（試作と同じ。消すのは定型文の窓で）
- **同じ名前**: 名前が同じ定型文をいくつでも作れる（id で見分ける）。上限 5000 件、本文は 10 万文字（UTF-16）まで
- **定型文の窓の保存**: ⌘S・「保存」で確定。ほかを選ぶ・新規・窓を閉じるときは、変更があって検証に通れば自動で保存する
  （通らなければ、選び直しは止めて理由を出す。閉じたときは前の値のまま）。新しい下書きは、開いたときのまま（履歴から作って手を付けていない）なら保存しない
- **同時に書いたとき**: 窓と別のプロセス（#6 の AI の口・手）がほぼ同時に書くと、後から書いた方が残る（設定と同じ。`SnippetController` は書く前に読み直すので、
  外で足した・消したものを窓の古い値で消さない）。窓で編集中の定型文が外で消されたら、書いていたものは新しい下書きとして残す
  （監視より先に保存したときは「その定型文はない」と出て下書きになるので、もう一度保存すると新しい定型文として入る）
- **壊れたファイル**: 読めない項目だけ飛ばす（窓の上に理由を出す）。JSON として読めなければ 0 件で動く。どちらも次に窓で保存するとき `snippets.broken.json` に退避してから書き直す

### AI の口（`AIAccess` / `AIGateway` / `AITools` / `MCPServer`・#6）

**守ること**（変えるときは `AIAccessTests`・`AIListTests`・`MCPServerTests` の漏れの検査と `make e2e-ai` を通す）

- 道具の応答・誤りの文・操作の記録に、中身（平文・データ・一覧用の平文）・コピー元ページの URL（ホスト名を除く）・ファイルの名前とパス・内容のハッシュを入れない。
  秘密の項目は大きさ・長さも返さない（秘密っぽい定型文も同じ）。定型文は本文と、本文の 1 行目から作った名前を返さない
- 門の外の出口（`--dump-metadata`）も同じ基準で見る（中身を推せる長さ・ハッシュを出さない。`MetadataDumpLeakTests` と `make e2e-ai` の長さ・ハッシュの照合が守る）
- 推した値が「あるかないか」も応答に出さない。AI の追加は人のコピーと別のハッシュの空間（`ContentHasher.aiAdded`）にし、人の項目に合流させない（`AIGuessOracleTests`）
- 履歴を減らしうる道具（削除と、設定を変える `settings_set`・`settings_reset`）は門の内側に置き、`destructiveHint: true` にする（`AISettingsGateTests`）
- AI の口をオンにする道具・CLI の命令・設定の項目を作らない。オンにするのは設定画面だけ（`AppController.setAIAccess`）。
  検証用の遠隔操作の `enableAIAccess` は `--debug-control`（隔離したときだけ）に置く
- 履歴と定型文の道具は呼ぶたびにオン・オフを DB から読む（長く動く MCP のプロセスが、オフに切り替えた後も使えてしまわないように）
- MCP の標準出力には JSON-RPC の応答だけを書く（ログを混ぜない）

**限界**

- **口を開ける別の経路**: 同じユーザーで動くプロセスは、DB の `meta` を `sqlite3` で書き換えればオンにできる。設定画面の切り替えを画面操作（アクセシビリティ）で押すことも防げない。
  防ぐのは、AI が CLI・MCP・設定ファイルの書き換えといった「ふつうの口」から自分で開けることまで
- **形式の情報から分かること**: コピー元アプリ・コピー元ページのホスト名・型名・時刻・秘密でないものの大きさ（文字数・行数）・秘密の形式の名前。
  秘密の判定が見逃したもの（上の「秘密の判定」の「見逃すもの」）は、ふつうの項目として大きさまで返る
- **期間**: `withinMinutes`・`olderThanMinutes` は最後にコピー・使った時刻で見る（取り込み直し・Makurip からの貼り付けで新しくなる）
- **AI が足したもの**: 人がコピーした同じ内容とは別の項目になる（一覧に同じ中身が 2 つ並びうる）。AI が足したもの同士は合流して先頭へ移るので、
  ある AI の相手は、別の AI の相手が前に足した内容があるかは分かる（人のコピーは分からない）。#24 より前に AI が足した項目は人のコピーと同じ空間にあるので、
  同じ内容をもう一度足すと別の項目になる
- **設定の CLI**: 人が使う `--settings` は門の外（シェルを使えるものは `sqlite3` でも門を開けられるので、ここだけ閉じても守れない）。
  AI エージェント向けの手順（`docs/ai-settings.md`）で、上限を下げる・記録しないアプリを外す・秘密の自動消去を延ばす・既定に戻す変更は、ユーザーに確かめてから行うよう頼んでいる
- **同時に書いたとき**: 動いているアプリの取り込みと AI の追加が同じ内容をほぼ同時に入れると、片方が失敗しうる（`content_hash` の重なり。失敗は `unavailable` で返る）。
  起動のときの `removeOrphanBlobs` が、AI がちょうど書いている途中の大きいデータ（64 KB 超）を消しうる（起動の一瞬だけ。消えた項目は貼れない）
- **知らせ**: 動いているアプリへの知らせは分散通知で、届かないことがある。一覧は開くたびに読み直すので見え方は変わらず、秘密の自動消去は次の見回り（取り込み・設定の変更・起動）で掛け直す
- **動いているかの判定**（`AppPresence`）: `instance.lock` を共有のロックで一瞬だけ試す。ちょうどそのときアプリが起動すると、アプリはロックを数回取り直す（0.3 秒ほどまで待つ）
- **大きさ**: 文字は 50 MB（型 1 つの上限）まで、画像のファイルも 50 MB まで、ファイルの参照は 100 個まで。MCP の要求 1 件は 128 MB まで（超えたら読まずに捨てて -32600）
- **相手の名前**: `initialize` の `clientInfo.name` をそのまま（40 文字まで・制御文字を除く）コピー元アプリの名前と記録に使う。相手が名乗った名前なので、偽れる
- **記録**: 500 件を超えたら古いものから捨てる。データフォルダがまだない（一度も起動していない）ときは書かない
