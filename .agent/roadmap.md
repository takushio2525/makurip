# ロードマップ（タスクリスト）

> フェーズは順番に別の worker が担当する。各フェーズの Issue 番号は GitHub の Issue と対応する。
> 要件の正本は `.agent/requirements.md`。着手前に必ず読むこと。

## フェーズ1: 土台（#1）

- [x] リポジトリ雛形（AGENTS.md / .agent / README / .gitignore / .gitattributes）
- [x] 一般ペーストボードの監視と全型・全項目の取り込み（大きいデータはディスクへ・サイズ上限・重複は先頭へ）
- [x] ConcealedType / TransientType / AutoGeneratedType の除外
- [x] メタデータ（時刻・コピー元アプリ・コピー方法・種類・コピー元ページ URL・ピン留め・フラグ欄）
- [x] 種類とコピー方法の判定（純粋関数 + 単体テスト）
- [x] SQLite への永続化（件数・容量の上限）
- [x] 全型ごと書き戻し → 元のアプリへフォーカスを返して ⌘V（書き戻しは新しい履歴にしない）
- [x] ⌃⌘V で開く仮の一覧（UI 層は `MakuripUI` に切り離し）
- [x] メニューバーのアイコン（仮）とメニュー
- [x] メタデータだけの書き出し（`--dump-metadata`）

## フェーズ2: 本番 UI・絞り込み・日本語検索（#2）

- ユーザーが選んだデザイン案（`~/dev/makurip-design/` で試作中）どおりに一覧を作り直す
- `Sources/MakuripUI/` を丸ごと差し替える（`HistoryPresenting` プロトコルを実装すれば本体はそのまま動く）
- 絞り込み: コピー方法（キー操作 / それ以外）・種類・コピー元アプリ
- 日本語検索: ひらがな/カタカナ・全角/半角を区別しない、ローマ字（「kopi」→「コピー」）
- アイコンの差し替え（「メモをめくる」イメージ）

## フェーズ3: 開発向けのプレビュー（#3）

- 画像・コードの大きなプレビュー、コードの色付け
- コマンドの先頭の「$ 」を外して貼る
- 取れる場合はコピー元のページ（`sourceURL`）を出す

## フェーズ4: 設定画面と全操作のキー割り当て（#4）

- 設定画面（件数上限・容量上限・除外アプリなど。既定値は `Limits.default`）
- すべての操作のキーを割り当て直せる（⌃⌘V は Clipy と同じなので変えられるように）
- グローバルショートカットは `HotKey`（keyCode + 修飾キー、Codable）で表現済み。記録 UI を足す

## フェーズ5: 秘密っぽいものの検出・マスク表示・自動消去（#5）

- 形式から API キー等を判定（中身を外へ出さない）。結果は `ClipFlag.secretLikely` に入れる
- 一覧ではマスク表示、一定時間後に自動消去

## フェーズ6: AI 用の口（CLI / MCP）（#6）

- 履歴への追加はできる（`ClipFlag.addedByAI` を付ける）
- AI には中身を見せず、形式の情報だけを渡す。秘密の判定はアプリの中で行う

## フェーズ7: 定型文（スニペット）（#7）

- 定型文の登録・呼び出し・貼り付け
