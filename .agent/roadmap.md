## フェーズ2.5: 候補窓（予測変換のような貼り付けと ↑↓ での差し替え）（#8）

フェーズ2 の後に置く（2026-10-31 追加。Issue は起票順の都合で #8）。

- ⌃⌘V を押すとすぐ最新の履歴を貼り、文字カーソルの横（右）に予測変換のような候補窓を出す。選んでいる行をカーソルの行の高さにそろえ、上が過去・下が新しい（↑ で過去へ）。並び順はターミナル式・予測変換式を設定で選べる
- 貼り方の既定はすぐ仮に貼って差し替える。ターミナルとチャット系のアプリは Tab（または Enter）で確定したときに初めて貼るのを既定にし、アプリごとに設定で変えられる
- ↑↓ で貼った中身を前・後の履歴に差し替え、Tab か Enter で確定、Esc で取り消して貼る前に戻す。1 キーで大きい一覧へ広げる
- 文字カーソルの位置は AX（`AXSelectedTextRange` → `AXBoundsForRange`）。取れないアプリ（ターミナル・Electron 製）はマウスの位置などで代わりにする
- 候補窓を出している間だけ ↑↓・Tab・Esc を CGEventTap で横取りする。日本語入力の変換中は横取りしない
- 差し替えは、直前に貼った範囲を選び直して貼るか ⌘Z（アプリによって挙動が違う）
- 今の作りから広げるときに直すところ（フェーズ1 時点の所見）は Issue #8 の本文にある

## フェーズ4: 設定スキーマ・設定画面・CLI での設定・全操作のキー割り当て（#4）

- 設定項目の一覧（スキーマ）を Core に 1 つ持ち、設定画面と CLI（このフェーズ）・MCP（フェーズ6）が共有する。項目ごとに ID・型・既定値・取りうる値・人が読める説明
- 設定を CLI で読み書きする口をこのフェーズで作る（フェーズ6 を待たない）。設定には秘密を入れない
- 設定画面（件数上限・容量上限・除外アプリなど。既定値はいま `Limits.default`）
- キーは全部自由に: 呼び出し・候補窓の ↑↓/Tab/Esc/広げる・一覧の中の操作・絞り込みの切り替え。重なったキーを検出する
- ⌃⌘V の動きを「すぐ貼るだけ／すぐ貼って候補窓／一覧を開く」から選べる（貼り付けのときに UI を出すか）
- いまの作りから寄せるときの所見は Issue #4 の本文
