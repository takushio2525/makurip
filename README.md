# Makurip（マクリップ）

Mac 用のクリップボード履歴アプリ。コピーしたものを種類を問わず保存しておき、⌃⌘V で呼び出して、元いたアプリにそのまま貼り付けられる。

名前は「MaClip」を日本語で読んだ音「マクリップ」に、「履歴を**まくる**」をかけている。

> 状況: フェーズ1（土台）を実装中。一覧の見た目は仮で、フェーズ2で作り直す。

## 何ができるか（予定を含む）

- テキスト・リッチテキスト・画像・PDF・ファイル・色・アプリ独自の形式まで、コピーされたものをそのまま保存する
- 再起動しても履歴が残る（保存先はこの Mac の中だけ）
- ⌃⌘V で一覧を開き、選ぶと元のアプリへ貼り付く
- どうコピーしたか（キー操作か、コピーボタンなどか）・種類・コピー元のアプリで絞り込める（記録はフェーズ1、絞り込みの画面はフェーズ2）
- パスワード管理アプリが「保存しないで」と印を付けたものは保存しない

詳しい要件とフェーズ分けは `.agent/requirements.md` と `.agent/roadmap.md` を参照。
