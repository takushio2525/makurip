# Makurip（マクリップ）

Mac 用のクリップボード履歴アプリ。コピーしたものを種類を問わず保存しておき、⌃⌘V で呼び出して、元いたアプリにそのまま貼り付けられる。

名前は「MaClip」を日本語で読んだ音「マクリップ」に、「履歴を**まくる**」をかけている。

> 状況: フェーズ4（設定画面・CLI での設定・全操作のキー割り当て）まで。次は秘密っぽいものの検出（`.agent/roadmap.md`）。

## できること

- テキスト・リッチテキスト・画像・PDF・ファイル・色・アプリ独自の形式まで、コピーされたものを**全項目・全型そのまま**保存する（貼り直すと元どおり）
- 再起動しても履歴が残る。保存先はこの Mac の中だけ（`~/Library/Application Support/com.takushio2525.makurip/`）
- ⌃⌘V で最新の履歴をすぐ貼り、文字カーソルの右に予測変換のような候補窓が出る。↑↓ で貼った中身を前後の履歴に差し替え、⇥ か ↩ で確定、esc で貼る前に戻す。もう一度 ⌃⌘V で一覧へ広げる。ターミナルとチャットのアプリでは、確定したときに初めて貼る
- ⌃⌥⌘V で、文字カーソルのすぐ下に小さな一覧（パネル）が出る。元のアプリを前面から外さないので、そのまま検索欄に文字を打てる
- 種類（テキスト / リッチテキスト / 画像 / ファイル / URL / 色 / コード / コマンド / その他）・コピー方法（キー操作か、それ以外か）・コピー元のアプリを記録し、それぞれで絞り込める
- 日本語に強い検索: ひらがなとカタカナ、全角と半角、大文字と小文字を区別しない。ローマ字でも引ける（「kopi」で「コピー」、「depuroi」で「ﾃﾞﾌﾟﾛｲ」）
- ⌘Y で選んだ項目を横に大きく表示（画像・テキスト・コード・URL・色・ファイル）
- コードは言語を見分けて色を付ける（Swift・JavaScript/TypeScript・Python・シェル・JSON・HTML/CSS・Go・Rust・C/C++・Java・Kotlin・Ruby・SQL・YAML）。プレビューの見出しと候補窓に言語名（「Swift 17 行」）
- コマンドは、ターミナルからコピーした先頭の「$ 」「% 」や `user@host:~$ ` などのプロンプトを外して貼る（一覧・候補窓とも）。⇧↩ なら外さずにそのまま貼る。保存してある履歴は変えない
- ブラウザ（Chrome 系・Safari）でコピーしたものは、コピー元のページをプレビューに出す（⌘O で開く）
- パスワード管理アプリが「保存しないで」と印を付けたもの（`org.nspasteboard.ConcealedType` 等）は保存しない
- 同じ内容は増やさず先頭へ移す。上限: 既定で 1000 件・合計 1 GB（ピン留めは数えない。設定で変えられる）。型 1 つ 50 MB を超えるものは落とす
- 設定画面（メニューの「設定…」か一覧で ⌘,）: ⌃⌘V の動き・候補窓の並び・件数と容量の上限・記録しないアプリ・確定まで貼らないアプリ・ログイン時に起動と、**すべての操作のキー**を変えられる
- AI エージェントに頼んで設定を変えられる（「候補窓は出さないで」「呼び出しを ⌥V にして」）。CLI（`Makurip --settings`）が設定画面と同じ項目と検証を使う（`docs/ai-settings.md`）
- メニューバーから: 一覧を開く（⌃⌥⌘V）・設定・記録を一時停止・履歴を消去・終了。Dock には出ない

### 候補窓のキー

| キー | 動き |
|---|---|
| ↑ ↓ | 上・下の候補に差し替える（ターミナル式の並びでは ↑ が 1 つ古い履歴） |
| ⇥ ／ ↩ | 確定して閉じる（↩ でも改行や送信はしない） |
| esc | 取り消して、貼る前の状態とクリップボードに戻す |
| ⌃⌘V | 一覧へ広げる（選んでいた項目を選んだ状態で開く） |
| それ以外のキー・窓の外のクリック | 確定して、そのキーはそのままアプリへ |

⌃⌘V の動きは「すぐ貼るだけ／すぐ貼って候補窓（既定）／一覧を開く」から選べる（設定画面の「呼び出しキーの動き」か
`Makurip --settings set hotkeyMode list`）。アクセシビリティの許可がないあいだは、⌃⌘V でも一覧を開く。

### 一覧のキー

| キー | 動き |
|---|---|
| ↑ ↓（⌃P ⌃N） | 選ぶ |
| Enter ／ ⇧Enter ／ ⌘Enter | 貼る ／ 書式を外して貼る ／ コピーだけ |
| ⌘1〜9 | その番号の項目をすぐ貼る |
| ⇥ ／ ⇧⇥ | 種類を切り替える（すべて・テキスト・リッチ・画像・コード・コマンド・URL・ファイル・色） |
| ⌘K | コピー方法で絞る（すべて → キー操作 → ボタンなど） |
| ⌘E | コピー元のアプリで絞る（ひらがな・ローマ字でアプリ名を探せる） |
| ⇧⌘P ／ ⌘P | ピン留めだけ表示 ／ ピン留めする・外す |
| ⌘Y ／ ⌘O ／ ⌘⌫ | 大きく表示 ／ コピー元のページを開く ／ 履歴から消す |
| ⌘, | 設定を開く |
| esc | 検索語を消す（空なら閉じる） |

上の表は既定のキー。**キーは全部付け替えられる**（設定画面で行を選んで Enter → 新しいキーを押す。重なったキーは前の割り当てから外す。
⌫ で初期値）。CLI なら `Makurip --settings set keys.method ⌘J`。

## 設定

設定はデータフォルダの `settings.json`（既定と違う値だけ）。設定画面・CLI・AI のどこから変えても、動いている Makurip がすぐに読み直す。

```sh
MAKURIP=~/Applications/Makurip.app/Contents/MacOS/Makurip
$MAKURIP --settings schema           # 項目の一覧（説明・取りうる値・頼みの例）。--json で機械向け
$MAKURIP --settings list             # いまの値（* は変えた項目）・キーの重なり
$MAKURIP --settings set maxItems 200
$MAKURIP --settings add excludedApps com.apple.Safari
$MAKURIP --settings reset --all
```

検証に通らない値（修飾キーのない呼び出しキー・他の操作と重なるキー・範囲外の件数など）は、理由を付けて拒否する。
AI エージェントに頼むときの手順と、頼みと項目の対応表は `docs/ai-settings.md`。

判定の仕方と、見分けられないもの（限界）は `.agent/conventions.md` の「判定の限界」にまとめてある。

## ビルドと導入

必要なもの: Xcode 26.2 以降（コマンドラインツール込み）・キーチェーンにある Apple Development の証明書。

```bash
# 1. 署名の設定（初回だけ）。証明書の一覧は security find-identity -v -p codesigning
cp Config/signing.local.env.example Config/signing.local.env
#    → MAKURIP_SIGN_IDENTITY に証明書の 40 桁のハッシュを入れる（このファイルは git 管理外）

# 2. 確認（lint・ビルド・単体テスト）
make check

# 3. 組み立てて署名し、~/Applications/Makurip.app へ入れる
make install

# 4. 起動
open ~/Applications/Makurip.app
```

### アクセシビリティの許可（初回だけ）

貼り付け（元のアプリへ ⌘V を送る）と、コピー方法の記録（⌘C を見る）と、候補窓（↑↓・⇥・↩・esc を候補窓が出ている間だけ受け取る）に必要。
システム設定 > プライバシーとセキュリティ > アクセシビリティ で **Makurip** をオンにする（メニューの「アクセシビリティを許可…」からも開ける）。

許可はコード署名と置き場所に紐づくので、Apple Development の証明書で署名し、いつも `~/Applications/Makurip.app` に入れる。
`make install` で入れ直しても許可は残る。アドホック署名だとビルドし直すたびに許可が消える。

許可がないあいだも履歴の記録はできる（コピー方法は「不明」になる）。貼り付けは、選んだものをペーストボードへ戻すところまでで止まる（自分で ⌘V を押せば貼れる）。候補窓は出さず、⌃⌘V でも一覧を開く。

## 開発

| 用途 | コマンド |
|---|---|
| ビルド | `make build` |
| 単体テスト | `make test` |
| lint / 整形 | `make lint` / `make format` |
| 取り込み・永続化の E2E（一般ペーストボードに触らない） | `make e2e` |
| 設定の E2E（CLI で変えて、動いているインスタンスにすぐ効くか） | `MAKURIP_APP=.app-build/Makurip.app make e2e-settings` |
| 一覧・貼り付けの E2E（画面ロック解除と許可が要る） | `scripts/e2e/paste.sh` |
| メタデータだけを書き出す | `~/Applications/Makurip.app/Contents/MacOS/Makurip --dump-metadata` |

検証では `--data-dir` で隔離したデータフォルダを使う（起動引数は `.agent/api.md`）。AI 向けの規約は `AGENTS.md`。
